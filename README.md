# Word Scramble x Roast Edition

A free online word scramble game with AI-powered roasting. Unscramble letters before time runs out, then get roasted based on your performance.

## Features

- 3 Difficulty Levels — Easy (5 words/90s), Medium (8 words/60s), Hard (12 words/45s)
- AI Roast System — 5 roast categories from Terrible to Amazing
- Hint System — Get first/last letter hints when stuck
- Share Results — Copy your score + roast to share on social media
- SEO Optimized — Full structured data, Open Graph, FAQ rich snippets
- Ad-Ready — 7 ad placement slots (leaderboard, sidebar, mobile, in-content)
- Mobile Responsive — Works on all devices
- No Dependencies — Pure HTML/CSS/JS, no frameworks needed

## Deploy

Just a single index.html — upload anywhere:

- GitHub Pages — Push and enable Pages in repo settings
- Netlify / Vercel — Drag and drop
- Any web server — Just serve the file

## Ad Integration

Replace the .ad-slot placeholder divs with your actual ad code (Google AdSense, Mediavine, etc.)
